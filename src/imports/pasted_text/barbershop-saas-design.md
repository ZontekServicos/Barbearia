Crie o design completo de um mini SaaS de agendamento e gestão para barbearia.

O sistema deve ser extremamente simples, rápido, moderno e intuitivo, pensado inicialmente para uma barbearia pequena com um único barbeiro, mas com estrutura visual preparada para futuramente suportar vários profissionais.

OBJETIVO DO PRODUTO

Permitir que clientes façam agendamentos rapidamente pelo celular e que o barbeiro tenha controle total sobre agenda, clientes, serviços, cancelamentos, faltas e possíveis abusos de agendamento.

O foco principal deve ser:
- facilidade de uso;
- poucas etapas;
- interface limpa;
- experiência mobile-first;
- aparência profissional;
- sensação de produto SaaS moderno.

IDENTIDADE VISUAL

Criar uma identidade moderna e elegante inspirada em barbearias premium, sem utilizar um visual antigo ou excessivamente clássico.

Estilo:
- minimalista;
- moderno;
- sofisticado;
- masculino sem exageros;
- cards arredondados;
- bom espaçamento;
- ícones simples;
- microinterações;
- tipografia moderna;
- excelente legibilidade.

Utilizar inicialmente uma paleta com:
- fundo escuro ou grafite;
- branco/off-white para contraste;
- uma cor de destaque elegante, podendo ser dourado, verde ou azul;
- evitar excesso de cores.

O design deve funcionar perfeitamente em celular, tablet e desktop.

2. LOGIN / CADASTRO RÁPIDO

Evitar formulários grandes.

O cliente deverá conseguir entrar utilizando principalmente o número de telefone.

Tela contendo:

“Qual é o seu número?”

Campo:
Telefone / WhatsApp

Botão:
“Continuar”

Depois exibir uma etapa de confirmação por código.

Exemplo:

“Enviamos um código para (71) 99999-9999”

Campo para código de 6 dígitos.

Botão:
“Confirmar”

Caso seja o primeiro acesso, solicitar apenas:

- nome;
- telefone já preenchido;
- opcionalmente data de nascimento.

Depois disso criar automaticamente a conta.

O número de telefone deve funcionar como identificador principal do cliente.

==================================================

O cliente deve conseguir realizar um agendamento em menos de 1 minuto.

Agendar
Meus horários
Perfil

Para o administrador utilizar:

Dashboard
Agenda
Clientes
Serviços
Menu

Criar empty states.

Exemplo:

“Você ainda não possui nenhum agendamento.”

Criar também estados de:

- loading;
- erro;
- sucesso;
- nenhum resultado;
- serviço indisponível;
- horário ocupado.

PROTÓTIPO

Criar protótipo navegável dos principais fluxos.

Fluxo cliente:

Landing Page
→ Agendar
→ Login por telefone
→ Selecionar serviço
→ Selecionar data
→ Selecionar horário
→ Confirmar
→ Agendamento realizado

Fluxo administrador:

Login
→ Dashboard
→ Agenda
→ Detalhes do agendamento
→ Perfil do cliente

Criar o projeto com estrutura organizada para posteriormente exportarmos o frontend e continuarmos o desenvolvimento do SaaS utilizando React/TypeScript.

Evitar gerar apenas uma landing page.

Quero todas as telas principais do produto e uma interface suficientemente consistente para servir como base real de desenvolvimento.
